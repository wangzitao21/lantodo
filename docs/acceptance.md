## 验证边界

本次未做 Android 真机或模拟器运行验证，不能把编译与签名校验当作新版本的锁屏、启动或跨设备实测。不同 Android 厂商后台策略、无互联网出口路由器、VPN / 多网卡、长期运行与真实断电仍需专门检查。

Windows 证书 / TLS 测试需要正常用户密钥容器访问；限制该访问的沙箱可能报证书加载失败，本次在允许该系统访问的环境重跑通过。部分构建出现 NU1900：当前网络未能获取 NuGet 漏洞数据，编译成功不代表在线漏洞审计已经完成。
