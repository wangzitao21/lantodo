## 验证边界

本次未连接 Android 真机或启动模拟器。相机扫码、相册识别的设备兼容性，滑动回弹、相册分享耗时和长列表性能仍需真机验证。二维码核心的实际编码 / 解码已测试，编译通过不代表真机交互测试。

本次 Windows WPF 软件渲染已成功导出截图，检查了主页面对齐、回收站灰白底色、通用设置、设备设置、备份与编辑卡片；测试同时检查紧凑宽度、回收站入口及弹窗键盘行为。

当前电脑没有 Docker CLI。NAS 服务及管理网页在 Windows 进程环境测试，Linux 容器和 amd64 / arm64 镜像需由现有 CI 或 Docker 主机验证，本次未宣称容器实测完成。

Windows TLS 与身份测试需要正常用户的 CNG 密钥服务，受限沙箱中的密钥加载失败不等于应用网络失败。所有设备须升级到本次构建；成员与移除通知需要存在可用连接路径。跨公网打洞、公共中继和厂商后台保活不在本次实现范围。

复现命令见 [构建说明](build.md)。构建工具、临时合成资料和测试输出在发布清理后不随源码上传。
