# v1.0.1 消息交互与同步状态验证

日期：2026-09-11。展示版本 1.0.1，Android 安装序号 16。

## 实现

- 首页仅显示“已保存到本机，暂未同步”或“已同步到最新”。在线状态依据已认证的实际连接；离线成员不阻止在线成员显示同步完成。
- 星标置顶、背景色作为消息字段同步和备份，编辑保留字段。无标记的旧消息序列化不变。
- 两端直接彻底删除采用一条带删除标记的最终修订，不先进入回收站；旧版本确认不能删除后来修改的内容。
- Android 返回保留原页面和滚动位置；设置切换频率只更新对应按钮。系统返回从其他页面回清单，再次返回到桌面。
- Android 录制单声道 AAC / M4A，最长 60 秒，松开发送、上滑取消；权限仅在首次使用时请求。离开界面释放麦克风，录音计时回调与单次录音绑定。
- 移除后台永久 CPU 唤醒锁；没有本地网络时暂停网络任务。成员管理与变化通知采用事件等待；多空间共享一次附件巡检，新设备发现唤醒各相关空间。

## Android 实际交互

使用独立 Android 15 x86_64 模拟器、正式签名 APK、24 条合成文字消息与虚拟麦克风录音，不使用个人清单或真实手机数据。

1. 滚动到列表中部，进入编辑后返回：返回前后可见消息及其屏幕坐标完全一致。
2. 滚动设置并切换兜底核对间隔：按钮文字更新，原屏幕坐标不变。
3. 子页返回按钮和标题的垂直中心一致。
4. 点击星标：消息移至顶部、星标变为黄色实心；选择薄荷背景后卡片着色。
5. 直接彻底删除：消息减少一条，回收站仍为空。
6. 回收站按系统返回到全部清单，再按返回退至桌面。
7. 首次录音请求麦克风权限；约 2 秒录音松开发送使消息数增加一条，上滑取消不增加消息；播放按钮进入“停止播放”状态并显示时长。
8. 加入独立 Windows 测试终端的空间：手机显示“已同步到最新”，本机和对端均显示绿色“在线”；Windows 收到可用的语音原件，手机收到带星标与背景色的电脑消息。
9. 关闭测试终端后，手机自动显示本机暂未同步；停止播放并退到后台，`dumpsys power` 的唤醒锁数量为 0。

## Windows 背景色菜单补充回归

用户反馈右键背景色无效后，定位到自定义 `MenuItem` 模板缺少子菜单弹出层。此前测试仅检查入口存在及已保存颜色的渲染，未覆盖展开操作。新增测试先复现“Background palette has no visible submenu popup”，修复后通过 WPF 自动化展开真实子菜单，依次选择五种颜色及默认，并检查保存结果、卡片背景即时刷新和选中标记；完整 Windows 布局回归同时通过。

## 限制与升级

模拟器不能证明真实设备的音质、长时间待机耗电或不同厂商的后台策略；这些需要真机验证。移除永久唤醒锁后，深度休眠期间同步可能延后，返回应用会立即补齐。在线状态的突然断连检测受连接超时影响。

Windows、Android 以及使用中的 NAS 应一起更新；旧客户端不认识新增的星标和背景色字段。Android 使用同签名覆盖安装，保留应用数据；Windows 覆盖程序文件时保留数据库、附件和空间配置。
