# LanTodo v1.0.1 使用说明

## 安装与记录

Windows 将 `LanTodo-v1.0.1-Windows.zip` 解压到可写位置，打开解压出的 `LanTodo-v1.0.1-Windows` 文件夹，运行其中的 `LanTodo.exe`。程序、依赖、数据库和附件默认放在同一目录；请移动整个文件夹，不要只复制 EXE。升级时退出旧版，将新包顶层文件夹内的程序文件复制到原程序目录并覆盖，保留原有数据文件，特别是 `LanTodo.sqlite`、`attachments/`、`attachment-index.json`、`spaces/` 和 `LanTodo.location`。旧版 `%TEMP%\.net\LanTodo*` 是 .NET 单文件依赖解压缓存，新便携包不再向那里解压；旧程序全部退出后可手动清理它的专属缓存。Android 安装 `LanTodo.apk`。覆盖升级 Android 时使用原签名，不要卸载或清除应用数据。

在首页底部输入内容，Windows 点击勾或按 Enter 保存，单击条目即可查看与编辑，右键完成或删除；Android 点击“发送”保存，点击条目查看详情，长按打开编辑/完成/复制/删除菜单，向垃圾桶方向滑动超过卡片一半后松手即删除；不足一半或手势取消时自动回弹。详情支持备注、日期和时间。日期时间用于安排与筛选，当前没有到期提醒。

“今日安排 / 今天”入口已移除，右上角日期按钮可以筛选任意日期或全部日期。Android 的三个横向入口是“清单、已完成、回收站”，另有“待确认”入口。Windows 清单顶部与左侧“全部清单”按钮对齐。

手机端“待确认”仅在存在冲突时出现，解决全部冲突后自动隐藏。

删除内容会先移入回收站（仅按钮使用粉色），可以恢复；“全部清除”彻底清空回收站，包含其他日期的条目。已完成页的“全部删除”会移到回收站。确认后又收到修改的记录会被拒绝或跳过，避免误删新版本。清除决定与删除历史仍保留用于同步，不会清空独立备份。

## 图片、文件与文件夹

Windows 在输入框按 Ctrl+V 或 Shift+Insert 可粘贴复制的图片、文件和文件夹，也可直接拖入窗口。发送按钮左侧的圆形加号可选择图片/文件或整个文件夹。附件先出现在输入框上方，点击 × 可移除；可带文字一起发送，也可单独发送。单条消息最多 32 个附件。

Android 输入区保留独立加号，输入文字后仍可添加附件。点击加号收起键盘并展开图片/文件面板，再点加号切回键盘，点输入框也可继续输入。文字或附件就绪时显示独立“发送”按钮；回车换行，输入框最多展开四行，更多内容在框内滚动。待发送附件可移除或继续添加，支持多选。Android 不提供整文件夹选择。

图片和文件保留原始字节，不降低分辨率、不做有损压缩；剪贴板中的位图没有原始文件编码时，以无损 PNG 保存。文件夹打包为不压缩 ZIP，保留子目录和空目录，接收后保存并解包。缩略图仅用于显示，保存原件不使用缩略图。图片可点开预览，文件卡片可保存原件到所选位置。

Windows 的附件卡片、缩略图和图片预览都支持右键“用默认程序打开”“打开文件所在文件夹”“另存为”。在附件所在文件夹删除原件后，回到窗口或稍后刷新会显示“已失效”；从未收到的原件显示“等待同步”。这个失效决定会同步到所有已连接设备，其他设备不会自动补回；对方离线时稍后收到。主动重新添加同一文件会创建新的附件引用，旧消息中的失效状态不会被复活。删除另存到外部的副本不影响程序内保留的原件。

未下载完的附件显示“等待同步”，收到原件并校验完成后才可保存。回收站保留仍可用的附件，以便恢复；彻底清除后，仅在没有其他清单、回收站记录或冲突版本引用时删除本机共享原件。文字修改历史仍保留，新备份不包含已清除且无人引用的原件，也不会改写已有备份。附件较多时请留意本机及 NAS 空间。

## 来源与设置

消息右侧默认用灰色小字显示最后修改设备；经过 NAS 中转时仍保留原修改设备，后续编辑或完成操作会归属操作设备。Windows 左下角“设置”和 Android 设置中可关闭显示，该偏好只影响本机。设置中的“本机昵称”用于给当前设备命名；NAS 网页可修改自身及所有空间成员的昵称，联网后自动传播到终端及消息来源显示。改名不会修改历史内容或设备身份。

## 窗口与返回

Windows 的消息编辑、修改历史、“设备与同步”和“备份与恢复”窗口可直接按 **Esc** 关闭，回到主界面；下次仍可正常打开。文件选择器与确认框中的 Esc 优先退出当前对话框。正在迁移或写入备份时，请等待操作完成。

关闭 Windows 主窗口后进入托盘；双击托盘图标或再次打开程序可恢复窗口。从托盘选择“退出 LanTodo”才能完全退出。Android 返回键先收起键盘，再返回上一页，主页返回才回到桌面。

## 设备与同步

每台设备最多可加入 32 个网络空间。空间只划分设备连接，不划分内容；所有清单、历史、回收站、草稿和附件均共用。手机同时加入家里和公司后，会在两个网络之间接力同步同一份内容。空间名称只在“设备与同步”中管理，首页不显示空间名称。

在“设置 → 设备与同步”中选择要管理的网络空间，仅改变下面显示的成员与连接地址，不改变清单或草稿。任一成员可生成授权码和二维码；另一设备扫码或粘贴加入，确认本机全部内容会通过这些连接同步。每次授权码五分钟有效，仅供一个设备身份使用；已建立的成员身份不会随授权码到期。

Windows 支持读取二维码图片，Android 支持相机扫码、相册读取或粘贴授权码，NAS 网页生成二维码与授权码。邀请码只用于加入，不需要每次同步时填写，也不需要每两台设备互相配对。

修改先保存本机，再自动传给可连接的成员。设备收到修改后可以继续转发，原设备不必始终在线；没有共同在线时间时，可通过另一成员保存并转交。每个设备的“已同步”只表示该设备已确认，不代表其他离线设备都已收到。

同一局域网自动发现；跨网络可在高级设置填写可达 IP / 域名与同步端口，或使用已有 VPN。授权码不能自动打通 NAT 或网络隔离。Windows 防火墙需允许专用网络 TCP 42851、UDP 42852。Docker 地址填写见下方 NAS 说明。

空闲时通过变化通知等待新修改，默认每小时完整核对，也可改为两小时；这不会延迟日常更新。“立即同步”用于主动重试。并发修改仍保留冲突，选择某个版本或删除，完整历史继续保留。

“移除”直接把设备移出整个空间，决定会传给其他成员；离线设备下次连接后收到。内部保留移除记录，旧副本不会让连接复活。对方已收到的本机数据不会被远程擦除，重新加入需要新授权码。“退出当前空间”也保留本机数据；其他空间不受影响。新建、加入另一空间无需退出当前空间。

“删除此空间”只退出并从列表移除该组网络连接，清单、历史、附件和草稿均保留。其他已加入的网络继续同步；移除最后一个网络后仍可查看和编辑全部内容。系统保留退出证明以通知离线成员，重新加入需要新的授权码。空间不是内容权限隔离区：若设备之间还有其他已授权路径，内容仍会通过该路径同步。

Android 可开启“后台与锁屏同步”、允许通知，并按需允许电池优化豁免。系统强制停止或电脑休眠时等待恢复运行，后台服务不能绕过全部系统限制。

## 可选 NAS 成员

NAS 使用相同的“添加设备 / 加入已有空间”入口。已有空间时让 NAS 加入一次即可，手机和电脑不必分别绑定 NAS。NAS 可以常在线保存修改供其他设备稍后接收；NAS 关闭后，可互通的其他成员仍能继续同步。

Docker 部署、地址映射、命令与备份见 [NAS 使用说明](nas.md)。

## 数据位置

Windows 默认将 `LanTodo.sqlite` 放在 EXE 同目录。备份页面显示实际完整路径。旧版自定义目录在首次启动时校验迁移到 EXE 旁，移动程序时应连同数据库与 attachments 目录一起移动。

自定义位置会在 EXE 旁产生 `LanTodo.location` 指引；移回 EXE 目录后自动删除。路径不可用时程序报错，不会创建空替代库。Android 数据保存在应用私有目录。

附件原件位于数据库旁的 `attachments/` 文件夹，Windows 可在“备份与恢复”中点击“打开附件文件夹”。所有可用原件全部直接放在这一个文件夹里，保留原文件名和扩展名；同名不同内容用“ (1)”等序号区分，不再每个文件占一个长编码目录。旧原件在启动时自动迁移，字节不重新编码。附件索引和失效记录保存在旁边的 `attachment-index.json`；不要单独删除这个索引。Android 内部路径通常为 `/data/user/0/app.lantodo.local/files/LanTodo/attachments/`，系统文件管理器无法直接访问，请使用“保存原件”导出。

`spaces/<内部标识>/` 仅保存网络成员、邀请与路由配置。旧版本分散在各空间的清单会按版本记录合并到根目录的统一数据库，重复历史去重，真实冲突保留；可用原件校验后汇入根目录附件文件夹，失效状态继续保留。合并完成后清理已迁移内容；占用中的旧副本暂时保留，下次启动重试清理。

从旧 JSON 存储升级时，程序校验并转换数据，保留历史和配对；转换成功后清理已经导入的旧文件。请勿再用不支持 SQLite 的旧程序打开该资料。

## 备份与恢复

选择“导出全部清单与历史”，将 `.lantodo.zip` 存到独立位置。备份包含全部清单的完整版本、回收站、删除与冲突、可用附件以及附件失效记录。原件尚未同步完整时，请先完成同步再备份；不含设备身份、配对和设置。使用“从备份合并恢复”导入，重复恢复不会复制相同历史，也不覆盖本机新修改。

换设备后重新配对。导出文件未加密，且包含已删除内容。程序不再自动创建每日 ZIP，需要主动备份。整库快照和格式说明见源码文档 `docs/backup.md`。

## v1.0.1 升级

Windows 新 ZIP 解压后只有 `LanTodo-v1.0.1-Windows/` 一个文件夹。首次安装直接打开里面的 EXE；升级时先退出旧版，将新文件夹内的程序文件覆盖到原程序目录，保留数据库、附件和 `spaces/` 配置，避免将新文件夹再嵌套进原程序目录。Android 使用同签名 APK 覆盖安装；NAS 重新构建并保留数据卷。各端均升级到本次构建后，旧空间内容会自动合并，原有网络成员保留，无需重新邀请。旧版逐台配对仍需明确升级，再用新授权码加入。

Android 支持从相册或文件管理器通过系统“分享”选择 LanTodo；单个或多个原件进入待发送区，点击发送才创建消息。分享优先读取发送方的原始附件列表，只有缺少该列表时才使用 ClipData，避免同时导入原图和相册生成的改名副本；同一次待发送区继续按内容哈希去重。首页日期按钮位于同步左侧，显示所选日期；待办数在本机保存状态右侧，清单与设置隐藏滚动条。


## 快速确认不同版本

Windows、Android 和 NAS 网页的“待确认内容”直接显示版本卡片：来源昵称、修改时间、内容、完成/删除状态及附件名称。点击“保留这个版本”或“采用删除”即可决定；也可“删除此条”。Windows、Android 提供“编辑合并…”继续自由编辑。若选择期间又收到新版本，会保留内容并要求重新确认，避免覆盖新修改。
