# LanTodo v1.0 使用说明

## 安装与记录

Windows 运行 `LanTodo.exe`；Android 安装 `LanTodo.apk`。覆盖升级 Android 时使用原签名，不要卸载或清除应用数据。

在首页底部输入一句话，点击勾或按键盘确认保存。Windows 双击条目查看详情，右键完成或删除；Android 点击条目查看详情。详情支持备注、日期和时间。日期时间用于安排与筛选，当前没有到期提醒。

“已完成”页面可批量删除全部已完成内容，包含日期筛选之外的条目。确认后又收到修改的条目会被跳过，历史继续保留。

## 窗口与返回

Windows 的“设备与同步”和“备份与恢复”窗口可直接按 **Esc** 关闭，回到主界面；下次仍可正常打开。文件选择器与确认框中的 Esc 优先退出当前对话框。正在迁移或写入备份时，请等待操作完成。

关闭 Windows 主窗口后进入托盘；双击托盘图标或再次打开程序可恢复窗口。从托盘选择“退出 LanTodo”才能完全退出。Android 返回键先收起键盘，再返回上一页，主页返回才回到桌面。

## 设备与同步

两端连接同一可互通局域网，打开设备页面。一端生成配对码，另一端粘贴并确认。配对码五分钟有效，已建立的配对长期保留，重启或更换 IP 不需要重新配对。

修改后立即尝试同步，空闲时默认每小时核对，可改为两小时；“立即同步”会主动尝试连接。不同设备同时修改同一条待办，会显示在“待确认”中，选择或编辑最终内容即可；双方历史都保留。

Windows 防火墙允许专用网络 TCP 42851、UDP 42852。访客 Wi-Fi、AP 隔离、VPN 和不同网段可能阻止发现。

Android 在设置里开启“后台与锁屏同步”、允许通知，并按需允许电池优化豁免。部分系统还需要允许后台自启动。后台运行会增加耗电，系统强制停止或电脑休眠时不能持续同步，恢复运行后重试。

## 可选 NAS 辅助同步

Windows 在「设备与同步 → NAS 辅助同步」、Android 在「设置 → NAS 辅助同步」输入 NAS 地址和配对码。每台 NAS 独立配对，修改先保存本机，上传成功后其他设备可以稍后上线接收；原设备不必同时打开。可暂停 NAS 同步并保留配置，也可同时保留局域网直连。

每个节点的最近确认只代表该节点已收到；手机系统停止应用后，下次运行才会补同步。Docker 部署、双 NAS 连接、管理命令及快照恢复见 [NAS 使用说明](nas.md)。

## 数据位置

Windows 默认将 `LanTodo.sqlite` 放在 EXE 同目录。备份页面显示实际完整路径，使用“更改数据位置”迁移到普通文件夹。程序校验成功后切换并移除原数据库，不覆盖目标已有资料。

自定义位置会在 EXE 旁产生 `LanTodo.location` 指引；移回 EXE 目录后自动删除。路径不可用时程序报错，不会创建空替代库。Android 数据保存在应用私有目录。

从旧 JSON 存储升级时，程序校验并转换数据，保留历史和配对；转换成功后清理已经导入的旧文件。请勿再用不支持 SQLite 的旧程序打开该资料。

## 备份与恢复

选择“导出清单与全部历史”，将 `.lantodo.zip` 存到独立位置。备份包含 JSON 格式的完整版本、删除与冲突，不含设备身份、配对和设置。使用“从备份合并恢复”导入，重复恢复不会复制相同历史，也不覆盖本机新修改。

换设备后重新配对。导出文件未加密，且包含已删除内容。程序不再自动创建每日 ZIP，需要主动备份。整库快照和格式说明见源码文档 `docs/backup.md`。
