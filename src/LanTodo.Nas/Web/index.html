LanTodo

升级连接规则

本机将创建统一空间，旧设备需要使用新授权码重新加入。清单、附件和历史均会保留；旧版逐台配对不会自动扩展为整个空间的授权。

空间成员

修改自动同步到可连接的成员，离线成员上线后补齐。任一成员都可邀请新设备。

加入已有空间

加入后，本机全部清单、历史和附件会与这些成员同步。设备同时加入多个空间时，也会在它们之间接力同步内容。

高级：邀请设备地址（通常无需填写）

添加设备

在另一台设备打开“设备与同步 → 加入已有空间”，扫码或粘贴授权码。5 分钟有效，请保持本机在线。

本机对外地址（Docker / 跨网络可在这里确认）

浏览器地址会作为建议填入。若容器映射了不同的同步端口，请改为实际端口。此地址会随授权码与成员信息传递。

高级连接与邀请记录

同一网络自动发现。跨网络需要可达地址或已有 VPN。NAS 是可选的常在线成员，其他设备也可保存并转发修改。

邀请记录

待确认内容

点击保留其中一个版本，或删除此条。历史始终保留；决定会自动同步到其他设备。

管理令牌

所有设备使用同一套同步规则。离线编辑、完整历史和冲突处理仍保留在每台设备上。
